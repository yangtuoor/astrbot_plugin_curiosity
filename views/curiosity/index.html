这一页在哪儿

找不到那些 API Key 在哪儿填，就看这里
  1. 打开 AstrBot 网页面板（就是你现在看的这个站点）。
  2. 点左边菜单里的「插件」。
  3. 在插件列表里找到「好奇心」，点它卡片上的「插件配置」按钮。
  4. 进去后能看到本插件的全部 35 项原生配置，API Key、接口地址都在那里面。
这一页（观察站）里的设置只有 25 项常用项，改坏了会当场告诉你哪里不对； API Key、SearXNG 地址、自定义接口这些「填错整轮都跑不了」的，故意留在那个原生配置页里。

搜索源

从哪儿捞网页。换一个源，下一次扫描就用新的
百度千帆 · 每天免费 100 次
还差一个「千帆 API Key」才能用。填法：左边菜单「插件」→ 找到「好奇心」→ 点「插件配置」→ 找到「千帆 API Key」，把 key 粘进去保存。这一页故意不放 key，因为 key 填错的话整轮扫描都会失败，却看不出是填错了。
博查 Bocha
还差一个「博查 API Key」才能用。填法：左边菜单「插件」→「好奇心」→「插件配置」→ 找到「博查 API Key」。
自建 SearXNG · 不用 key
还差一个「SearXNG 地址」才能用。填法：左边菜单「插件」→「好奇心」→「插件配置」→ 找到「SearXNG 地址」，填你自建实例的网址。另外别忘了在 SearXNG 自己的 settings.yml 里把 json 格式打开，否则它不会返回结果。
自定义 JSON 接口
适合接自己搭的或者别人的搜索接口。要填「接口地址、请求方式、API Key、请求头、请求体、从哪个字段取结果」这六样，填法：左边菜单「插件」→「好奇心」→「插件配置」，往下找同名的六项。请求体里可以用 {query}（换成搜索词）、{key}（换成 API Key）、{top_k}（换成条数）这三样东西（保存前原样写进请求体里就行）。
AstrBot 自带搜索
直接用 AstrBot 自己配好的网页搜索，不用另外填 key。要是它失败了，会自己往下试千帆、博查、SearXNG（你配了哪个就用哪个）。
不联网，直接问模型
它不会去网上搜，只会凭模型自己的记忆回答。这样容易说出根本不存在的消息，而且照样要花 token。一般不选这个。
